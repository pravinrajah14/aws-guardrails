- Afterwards the report was edited by hand: `order_id` now shows as typed (`A100`, or `a100` in the lowercase variant) because the first run's table showed the case-folded form. No result changed. All 90 recorded answers were replayed through the current checks with 0 differences.

- Prompt changes made before this run, while trying the demo sentences by hand (no expected answer changed):
  1. The model gave the whole sentence as the amount span, which hid "production" inside it. Code now checks qualifiers and unassigned numbers against where the value itself sits, not the model's span; the prompt asks for the shortest span.
  2. It called "Only refund if" a qualifier and "a manager" vague. The prompt now says which words are not qualifiers and has four worked examples, none of them a demo or test sentence.
  3. It puts "recently" in the window slot instead of vague_terms (once with an invented value "2 hours"). Code rejects any amount or duration span with no number in it and keeps those words as a vague term. No vague word is written in code.
- The prompt was tuned on the demo sentences, so this table is not a held-out test.
